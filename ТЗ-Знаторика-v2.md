## 1. Общее описание

**Знаторика** — образовательная платформа для дошкольников (4–7 лет) и учеников начальной школы (1–4 класс). Платформа предоставляет интерактивные тренажёры, генераторы заданий, пособия для учителей и другие образовательные материалы по всем предметам.

**Слоган:** Учись. Тренируйся. Сдавай.

**Логотип:** Рыжая весёлая белка внутри буквы З на фиолетовом фоне с жёлтыми звёздами (см. приложенное изображение).

**Целевая аудитория:**
- Родители дошкольников и школьников (платят подписку)
- Учителя начальной школы (платят подписку, скачивают материалы)
- Дети 4–11 лет (используют через родителей/учителей)

**Модель монетизации:**
- Подписка: **299 ₽/мес** (одна для родителей и учителей)
- Генераторы: 10 раз бесплатно без регистрации, затем подписка
- Прочий контент: часть бесплатна, полный доступ по подписке

## 3. Контент и форматы

### 3.1 Форматы материалов

1. **Теория** — текстовые объяснения тем (бесплатно для всех)
2. **Шпаргалки** — краткие выжимки, формулы, правила (бесплатно)
3. **Тесты** — проверка знаний с проверкой ответов (частично бесплатно, полностью по подписке)
4. **Тренажёры** — интерактивные упражнения с обратной связью (только по подписке)
5. **Рабочие листы** — печатные задания в формате PDF (только по подписке)
6. **Генераторы** — автоматическая генерация примеров, прописей, кроссвордов, диктантов, изложений (10 раз бесплатно без регистрации, затем подписка)
7. **Приложения** — встроенные интерактивные игры/тренажёры (тренажёры умножения, алфавита, неправильных глаголов и т.д.)
8. **Полезные материалы для учителя** — методички, поурочные планы, готовые задания для класса (только по подписке)
9. **Карточки** — флеш-карты для запоминания (только по подписке)
10. **ВПР** — варианты всероссийских проверочных работ с разбором (только по подписке)

### 3.2 Предметы (все сегменты)

- Математика
- Русский язык
- Английский язык
- Окружающий мир
- (+ дополнительные по запросу)

### 3.3 Примеры генераторов

- Примеры на сложение, вычитание, умножение (с настройкой диапазона и количества)
- Прописи (буквы, слова, предложения)
- Кроссворды (автогенерация по теме)
- Диктанты (подборка слов для диктовки)
- Изложения (подготовленные тексты с вопросами)

### 3.4 На старте готово

- **10 тем** (распределены по сегментам и предметам)
- **~20 тренажёров** (из существующих HTML/TSX файлов)
- **Генераторы**: примеры, прописи (основные типы)
- **Шпаргалки и теория** для этих 10 тем

## 4. Архитектура и URL-схема

### 4.1 Структура каталога

```
/                                      — главная (лендинг)

/4-5-let                               — дошкольники 4–5 лет
/4-5-let/{предмет}                     — /4-5-let/matematika
/4-5-let/{предмет}/{тема}              — /4-5-let/matematika/schet-do-10
/4-5-let/{предмет}/{тема}/{формат}     — …/teoriya | test | trenazher | …

/6-7-let                               — дошкольники 6–7 лет
/6-7-let/{предмет}/{тема}/{формат}     — структура аналогична

/1-klass … /4-klass                    — начальная школа
/1-klass/{предмет}/{тема}/{формат}     — /1-klass/matematika/slozhenie-do-20/trenazher

/generator/{тип}                       — /generator/primery /generator/propisi
/podpiska                              — страница подписки и оплаты
/admin                                 — админ-панель (только для владельца)
```

### 4.2 Форматы в URL

Форматы доступны как вкладки на странице темы или как отдельные URL:
- `…/teoriya` — теория
- `…/shpargalka` — шпаргалка
- `…/test` — тесты
- `…/trenazher` — тренажёры
- `…/rabochiy-list` — рабочие листы (PDF)
- `…/vpr` — ВПР (для начальной школы)
- `…/kartochki` — карточки

## 5. Функциональные требования

### 5.1 Фронтенд

#### Главная страница (лендинг)
- Секции по целевым сегментам (дошкольники, начальная школа)
- Быстрые ссылки на популярные темы
- Блок подписки (299 ₽/мес)
- SEO-оптимизированный контент

#### Навигация по каталогу
- Двухточечный вход: по сегменту ИЛИ по предмету
- Иерархия: Сегмент → Предмет → Тема (форматы — вкладки или URL)
- Хлебные крошки на всех страницах
- Поиск по темам и ключевым словам
- Адаптивный дизайн для телефона, планшета, десктопа

#### Страница темы
- Вкладки форматов (теория, шпаргалка, тест, тренажёр, листы и т.д.)
- Для бесплатного контента — сразу доступно
- Для платного — кнопка "Оформить подписку" с всплывающим окном

#### Генератор
- Форма с параметрами (диапазон, кол-во заданий, тип)
- Кнопка "Сгенерировать"
- Показатель: "Осталось X из 10 бесплатных"
- После 10 раз — предложение подписки
- Вывод на экран + печать + скачивание PDF

#### Страница подписки
- Описание плана
- Кнопка "Оформить подписку" → перенаправление на оплату (ЮKassa)
- FAQ (свёрнуты/развёрнуты)

#### Админ-панель (только для владельца)
- Прямой доступ через `/admin` (простая авторизация)
- Функции:
  - Просмотр аналитики (пользователи, регистрации, подписки, материалы)
  - Изменение цены подписки
  - Просмотр всех платежей (таблица с фильтрацией)
  - Добавление доступа пользователю вручную (email + сегмент)
  - Встроенный поиск по пользователям и платежам

### 5.2 Бэкенд и API

#### Авторизация
- Регистрация: email + пароль
- Логин: email + пароль
- Сессии (JWT или session cookie)
- Восстановление пароля по email

#### Платежи
- Интеграция с ЮKassa
- Webhook для обновления статуса подписки
- Проверка активности подписки при запросе платного контента

#### Лимиты генератора
- Счётчик использований генератора для незарегистрированного пользователя (cookie/localStorage: 10 раз)
- Для зарегистрированного без подписки: счётчик в БД (10 раз/день или абсолютный лимит)
- Для подписчика: без лимита

#### Аналитика
- Счёт активных пользователей, регистраций по дням
- Топ-10 популярных тем и форматов
- Воронка: регистрация → оплата (сколько зарегистрировалось, сколько подписалось)
- Статус платежей (успешные, отменённые, возвраты)
- Данные для расчётов (выручка по дням, средний чек)

#### Контент
- Админ может загружать теорию, шпаргалки, листы (Markdown → HTML или загрузка HTML)
- PDF для листов хранятся на сервере
- Генераторы: параметры хранятся в БД, логика расчёта на фронте или бэке (например, генератор примеров = случайные числа в диапазоне)

### 5.3 SEO

- SSR/SSG через Next.js App Router
- Meta-теги (title, description, og:image) для каждой страницы
- Structured Data (JSON-LD) для учебных материалов
- sitemap.xml, robots.txt
- Динамическое создание og:image для шеринга в соцсетях
- ЧПУ (clean URLs без параметров)
- Быстрые страницы (Core Web Vitals: LCP < 2.5 с)

## 6. Дизайн и UX

### 6.1 Стиль

- **Палитра:** Фиолетовый (основной — `#7C3AED`), оранжевый (акцент — `#F97316`), белый, тёмный фон для ночного режима

- **Иерархия:** крупные заголовки, понятные иконки (эмодзи или SVG), контрастный текст

### 6.2 Компоненты

- Карточка темы (изображение + название + краткое описание)
- Вкладки форматов
- Кнопки (большие, с эффектом наведения)
- Модальное окно подписки
- Таблица платежей (админка)
- Графики аналитики (простые столбчатые или линейные)

### 6.3 Адаптивность

- Телефон: вся навигация в меню-бургер, одна колонка контента
- Планшет: боковая навигация или две колонки
- Десктоп: трёхколонный или двухколонный layout

## 7. Технический стек

### 7.1 Фронтенд
- **Framework:** Next.js 14+ (App Router)
- **Язык:** TypeScript
- **UI-компоненты:** собственные или Headless UI + Tailwind CSS
- **Иконки:** SVG или эмодзи
- **Тренажёры:** встроенные React-компоненты (из существующих .tsx файлов)
- **PDF:** react-pdf или html2pdf для печати листов

### 7.2 Бэкенд
- **Runtime:** Node.js 18+
- **API:** Next.js API Routes или отдельный Express/Fastify
- **БД:** PostgreSQL 14+
- **ORM:** Prisma или TypeORM

### 7.3 Платежи и интеграции
- **Платежи:** ЮKassa SDK
- **Email:** Resend или SendGrid (для уведомлений, восстановления пароля)
- **CDN:** CloudFlare (статика, PDF)
- **Хостинг:** Vercel (Next.js) или самостоятельный VPS (DigitalOcean, Hetzner)

### 7.4 Мониторинг и аналитика
- **Встроенная аналитика:** админ-панель с графиками (собственная реализация)
- **Опционально:** Sentry (ошибки), LogRocket (сессии пользователей)

## 9. Юридические требования (июль 2026)

### 9.1 Защита данных

- **Закон 152-ФЗ (РФ):** соответствие обработке персональных данных детей
- **Согласие на обработку:** обязательное при регистрации (для родителя)
- **Хранение данных:** только на серверах в РФ или совместимых с GDPR
- **Удаление данных:** возможность удалить аккаунт и все данные по запросу

### 9.2 Документация

- **Политика конфиденциальности:** публичная, доступна на сайте
- **Условия использования:** указание возрастных ограничений (4+), запреты на нарушения
- **Согласие на обработку ДПД:** отдельный чекбокс при регистрации
- **COPPA (если привлекаются US-пользователи):** дополнительное согласие для детей до 13 лет

### 9.3 Авторские права

- **Контент:** указание авторства, источников (в подвале или в метаданных)
- **Лицензирование:** если используется контент третьих лиц — наличие лицензии

### 9.4 Платежи

- **Возврат средств:** политика возврата подписки (если отменили в течение N дней)
- **Раскрытие информации:** чёткая цена, период, автопродление

### 9.5 Кукиз и трекинг

- **Cookie Policy:** согласие на обязательные и аналитические куки
- **Яндекс.Метрика / GA:** согласие пользователя (даже если технически необходимо)
