# Деплой Знаторики на продакшен

## Часть 1 — что нужно сделать тебе (я не могу за тебя)

### 1. Зарегистрироваться на Beget
1. Перейти на https://beget.com
2. Зарегистрироваться, привязать способ оплаты
3. Заказать облачный сервер (VPS):
   - Конфигурация: **2 ядра / 4 ГБ RAM / 40 ГБ SSD** (~990 ₽/мес)
   - ОС: **Ubuntu 22.04 LTS**
   - Дата-центр: **обязательно Россия, Санкт-Петербург** (важно для ФЗ-152)
   - Включить опцию автоматических бэкапов сервера в панели (дополнительно к скрипту бэкапов БД, который настрою я)

### 2. Передать мне доступ к серверу
После заказа Beget пришлёт:
- IP-адрес сервера
- Логин (обычно `root`)
- Пароль или SSH-ключ

Передай эти данные — дальше всё настрою сам по SSH.

### 3. Домен
Купить домен `znatorica.ru` (любой регистратор — Reg.ru, Timeweb и т.д., ~200–900 ₽/год) и направить его на IP-адрес сервера (я подскажу, какую A-запись прописать в панели регистратора, когда сервер будет готов).

### 4. YuKassa — реальные ключи для приёма платежей
1. Зарегистрироваться на https://yookassa.ru как продавец (ИП/самозанятая/ООО — в зависимости от твоей формы деятельности)
2. Пройти проверку (обычно 1-2 дня)
3. В личном кабинете ЮKassa получить **Shop ID** и **Секретный ключ**
4. Передать их мне — впишу в конфигурацию сервера

### 5. (Опционально) SMTP для реальной отправки писем
Сейчас письма подтверждения работают в тестовом режиме (код виден в логах сервера). Для реальной отправки нужен email-провайдер:
- Яндекс 360 для бизнеса (рекомендую) — https://360.yandex.ru/business/
- Или Mail.ru для бизнеса

Зарегистрировать домен почты (например `noreply@znatorica.ru`) и передать мне SMTP-логин/пароль. Можно сделать и позже — сайт будет работать и без этого, письма просто продолжат логироваться в консоль сервера.

## Часть 2 — что сделаю я по SSH после получения доступа

Это не для выполнения тобой — просто чтобы ты понимала, что происходит.

1. Подключение к серверу, установка Docker и Docker Compose
2. Клонирование репозитория проекта на сервер
3. Заполнение `.env.production` реальными значениями (пароль БД, JWT-секрет, ключи YuKassa и т.д. — генерирую случайные секреты через `openssl rand -hex 32`)
4. Запуск `docker compose up -d --build` — поднимает базу данных и само приложение
5. Применение миграций базы данных (`prisma migrate deploy`, встроено в команду запуска)
6. Установка и настройка Nginx (файл `deploy/nginx.conf`) — проксирует запросы с 80/443 порта на приложение
7. Получение бесплатного SSL-сертификата через certbot (Let's Encrypt) — сайт заработает по https
8. Настройка автоматических ежедневных бэкапов базы данных через `deploy/backup.sh` + cron
9. Проверка, что сайт открывается по адресу https://znatorica.ru, регистрация/оплата работают

## Часть 3 — после деплоя

- Периодически буду проверять логи на ошибки
- При обновлении кода — пересборка через `docker compose up -d --build` (займёт 1-2 минуты, коротким downtime)
- Раз в месяц можно проверять, что бэкапы реально создаются (`ls /opt/znatorika/backups`)
