# 🔐 Защита персональных данных - ФЗ-152 (Федеральный закон)

## ✅ Соответствие нормативной базе

Платформа "Знаторика" полностью соответствует:
- 📜 **ФЗ-152** "О защите персональных данных" (27.07.2006)
- 📜 **ФЗ-54** "О применении ККМ" (хранение платежей)
- 📜 **ГОСТ Р 56860** (безопасность электронных платежей)
- 📜 **НК РФ** (налоговый учёт - 7 лет)

## 🔒 Технические меры защиты

### Шифрование
```typescript
// AES-256 для чувствительных данных
encryptData(data)     // Зашифровать
decryptData(encrypted) // Расшифровать
```

### Хеширование паролей
```typescript
// bcryptjs - необратимое хеширование
hashPassword(password)     // Хешировать пароль
comparePassword(password)  // Проверить пароль
```

### Передача данных
- 🔐 HTTPS/TLS на всех страницах
- 📡 Шифрование в пути передачи

### Логирование доступа
```typescript
logDataAccess(userId, action, dataType)
// Логирует все обращения к данным для аудита
```

## 📊 Какие данные собираются и где

### Таблица User
- `id` - уникальный идентификатор
- `email` - электронная почта
- `passwordHash` - хеш пароля (bcryptjs)
- `role` - роль пользователя
- `createdAt` - дата регистрации
- `updatedAt` - дата последнего обновления

### Таблица Payment
- `id` - уникальный идентификатор
- `kassaId` - ID платежа в YuKassa
- `amount` - сумма платежа
- `currency` - валюта (RUB)
- `status` - статус (pending/succeeded/canceled)
- `createdAt` - дата платежа
- `updatedAt` - дата обновления

### Таблица Subscription
- `userId` - ID пользователя
- `status` - статус подписки (active/inactive)
- `startDate` - дата начала
- `endDate` - дата окончания
- `autoRenew` - автопродление
- `paymentId` - ID связанного платежа

### Таблица GeneratorUse
- `userId` - ID пользователя
- `sessionId` - ID сессии
- `type` - тип генератора
- `createdAt` - дата использования

### Таблица PageView
- `url` - адрес страницы
- `userId` - ID пользователя (опционально)
- `createdAt` - дата просмотра

## ⏰ Сроки хранения данных

| Тип данных | Срок | Обоснование |
|------------|------|-------------|
| Учётные данные (email, пароль) | До удаления + 30 дней | ФЗ-152 ст. 21 |

| Подписка | До удаления аккаунта | ФЗ-152 ст. 21 |

## 📝 Процесс удаления данных

### Запрос пользователя
1. Пользователь нажимает "Удалить все мои данные" на `/account/data`
2. Код подтверждения отправляется на email
3. Пользователь вводит код
4. Запускается функция `deleteUserData(userId)`

### Что удаляется
```typescript
await db.generatorUse.deleteMany({ where: { userId } })     // Исторія генератора
await db.payment.deleteMany({ where: { userId } })          // Платежи
await db.subscription.deleteMany({ where: { userId } })     // Подписка
await db.pageView.deleteMany({ where: { userId } })         // Просмотры

// Пользователь анонимизируется
await db.user.update({
  data: {
    email: `deleted-${randomHash}@deleted.local`,
    passwordHash: '',
    role: 'deleted'
  }
})
```

### Что НЕ удаляется
- 📋 Логи доступа (7 лет по ФЗ-54)
- 💳 Платежные логи (7 лет по НК РФ)
- 🔍 Логи безопасности (аудит)

## 📧 Данные третьих сторон

### YuKassa (обработчик платежей)
- Передаём: ID платежа, сумму, способ оплаты
- Не передаём: Email, пароль, историю
- Ответственность: их политика конфиденциальности
- Контроль: соглашение об обработке данных

### Email сервис (уведомления)
- Передаём: Email адрес только для писем
- Не передаём: Другие данные
- Контроль: условия использования сервиса
