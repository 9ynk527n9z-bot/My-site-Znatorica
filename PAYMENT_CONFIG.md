# 💳 Конфигурация платежей - Только РФ способы (Июль 2026)

## ✅ РАЗРЕШЁННЫЕ способы оплаты в России

### 1. 🇷🇺 Карты MIR (Национальная платёжная система)
- **Описание:** Единственная национальная платёжная система России
- **Применение:** Дебетовые и кредитные карты MIR
- **Параметр:** `bank_card`
- **Статус:** ✅ Активен

### 2. 📱 СБП (Система быстрых платежей)
- **Описание:** Моментальный перевод по номеру телефона
- **Банки:** Сбербанк, ВТБ, Альфа-Банк, Тинькофф и др.
- **Параметр:** `sbp`
- **Статус:** ✅ Активен (РЕКОМЕНДУЕТСЯ)

### 3. 🏦 Сбербанк Онлайн
- **Описание:** Прямой платёж через приложение Сбербанка
- **Параметр:** `sberbank`
- **Статус:** ✅ Активен

### 4. 💛 Яндекс.Касса
- **Описание:** Электронный кошелёк от Яндекса
- **Параметр:** `yandex_kassa`
- **Статус:** ✅ Активен

### 5. 💳 QIWI
- **Описание:** Электронный кошелёк QIWI
- **Параметр:** `qiwi`
- **Статус:** ✅ Активен (при наличии лицензии)

### 6. 📞 Мобильные операторы
- **МТС:** через счёт оператора
- **Beeline:** через счёт оператора
- **Параметр:** `mobile_payment`
- **Статус:** ✅ Активен

## 🔧 Настройка YuKassa

### 1. Получить учетные данные
1. Зайти на [yookassa.ru](https://yookassa.ru)
2. Зарегистрировать мерчанта
3. Получить **Shop ID** и **API Key**

### 2. Установить в .env
```env
YOOKASSA_SHOP_ID="your-shop-id-here"
YOOKASSA_API_KEY="your-api-key-here"
```

### 3. Настроить webhook в YuKassa dashboard
```
URL: https://your-domain.ru/api/payments/webhook
Method: POST
Content-Type: application/json
```

### 4. Включить только разрешённые методы в YuKassa админке:
- ✅ Карты MIR
- ✅ СБП
- ✅ Сбербанк
- ✅ Яндекс.Касса
- ✅ QIWI
- ✅ Мобильные платежи
- ❌ Отключить все заблокированные

## 💻 Использование в коде

### API Endpoint
```typescript
POST /api/payments/create
{
  "paymentMethod": "bank_card" | "sbp" | "sberbank" | "yandex_kassa" | "qiwi" | "mobile_payment"
}
```

### Проверка разрешённости метода
```typescript
import { isMethodAllowed } from '@/lib/payment-methods';

const allowed = isMethodAllowed('bank_card'); // true
const blocked = isMethodAllowed('visa'); // false
```

### Получить список методов
```typescript
import { getAllowedMethods } from '@/lib/payment-methods';

const methods = getAllowedMethods();
// [
//   { id: 'bank_card', name: 'Карта MIR', icon: '🇷🇺' },
//   { id: 'sbp', name: 'СБП (Быстрые платежи)', icon: '📱' },
//   ...
// ]
```

## ⚖️ Соответствие законодательству РФ

### Нормативная база:
- 📜 ФЗ-54 (Закон о ККМ)
- 📜 ФЗ-161 (О национальной платёжной системе)
- 📜 Постановление Правительства РФ о санкциях
- 📜 ГОСТ Р 56860 (безопасность электронных платежей)

### Рекомендации:
1. ✅ Используйте только методы с российской юрисдикцией
2. ✅ Храните логи платежей 7+ лет
3. ✅ Выдавайте кассовые чеки (интеграция с ККМ)
4. ✅ Раскрывайте информацию об обработке данных
5. ✅ Соблюдайте 152-ФЗ (защита персональных данных)
