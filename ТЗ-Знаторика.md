# Техническое задание — образовательная платформа «Знаторика»

**Домен продукта:** образование (дошкольники + школа 1–11 класс, подготовка к ЕГЭ / ОГЭ / ВПР)
**Слоган:** «Учись. Тренируйся. Сдавай.»
**Дата документа:** 2026-07-03
**Статус проекта:** есть лендинг (`index.html`) и ~20 автономных HTML/TSX-тренажёров. Единой платформы, роутинга, аккаунтов и оплаты пока нет.

---

## 1. Цель проекта

Создать единую веб-платформу с образовательным контентом и интерактивными тренажёрами для детей от 3 лет до выпускников школы. Пользователь заходит, выбирает возраст/класс → предмет → тему → формат материала (теория, тест, тренажёр, рабочий лист, шпаргалка, раскраска, PDF, генератор). Часть контента бесплатна, полный доступ — по подписке 299 ₽/мес.

### Бизнес-цели
- Привлечь родителей дошкольников и школьников, а также самих учеников.
- Конверсия бесплатного пользователя в платную подписку.
- Удержание за счёт большого каталога тем и регулярно обновляемого контента.

---

## 2. Целевая аудитория

| Сегмент | Возраст | Кто платит | Ключевая потребность |
|---|---|---|---|
| Дошкольники | 3–7 лет | родители | подготовка к школе: счёт, чтение, письмо, логика, память, внимание |
| Начальная школа | 1–4 класс | родители | математика, русский, английский, окружающий мир |
| Средняя школа | 5–9 класс | родители / ученик | все предметы + подготовка к ОГЭ и ВПР |
| Старшая школа | 10–11 класс | ученик / родители | подготовка к ЕГЭ |

## 3. Текущее состояние (что уже есть)

**Лендинг** `index.html` — главная страница с секциями: hero, «Найди свой раздел», «Все предметы» (12 предметов), «Любой формат для любой задачи», «Начальная школа», «Подготовка к школе», «Английский», «Генераторы заданий», блок подписки (299 ₽/мес), FAQ, футер. Тёмная тема, фиолетово-оранжевая палитра, sticky-навигация.

**Готовые тренажёры (автономные HTML/TSX):**
- Английский: `alphabet-app.html`, `english-words.html`, `irregular-verbs.html`/`.tsx`, `colors-app.html`, `color-trainer.html`, `numbers-app.html`, `shapes-colors.html`

**Проблемы текущего состояния:**
- Ссылки в лендинге ведут на «красивые» URL (`/1-klass/matematika/...`), которых физически нет.
- Файлы не связаны роутингом, дублируются (`color-trainer.html` / `color-trainer 2.html`), имена с пробелами.
- Нет аккаунтов, подписки, оплаты, единого дизайна и общей навигации внутри тренажёров.

## 4. Структура сайта и URL

Единая схема ЧПУ-адресов (уже заложена в лендинге, нужно реализовать):

```
/                                     — главная (лендинг)
/{возраст|класс}                      — /3-goda /5-let /1-klass … /11-klass /ege /oge
/{класс}/{предмет}                     — /1-klass/matematika
/{класс}/{предмет}/{тема}              — /1-klass/matematika/slozhenie-do-10
/{класс}/{предмет}/{тема}/{формат}     — …/teoriya | test | trenazher | rabochiy-list |
                                         shpargalka | raskraska | pdf | kartochki | igra
/generator/{тип}                       — /generator/primery /generator/propisi
/podpiska                              — страница подписки и оплаты
/lichnyy-kabinet                       — профиль, прогресс, история
```

**Форматы материалов (сущность «Формат»):**
Теория · Тест · Тренажёр · Рабочий лист · Шпаргалка · Раскраска · PDF · Карточки · Игра · Генератор.

## 5. Функциональные требования

### 5.1 Каталог и навигация
- Иерархия: Возраст/класс → Предмет → Тема → Формат.
- Главная с секциями по сегментам (как сейчас) + рабочие ссылки.
- Хлебные крошки на всех внутренних страницах.
- Поиск по темам/предметам.
- Адаптивность: телефон, планшет, десктоп (основная аудитория — планшет/телефон родителя и ребёнка).

### 5.2 Интерактивные тренажёры
- Перенести существующие HTML/TSX-тренажёры в единый движок и дизайн.
- Общие механики: проверка ответа, счёт правильных/неправильных, звук, повтор, прогресс-бар, результат в конце.
- Сохранение прогресса для авторизованных пользователей.

### 5.3 Генераторы заданий
- Генерация примеров (математика), прописей, сравнений и т.п. с параметрами (диапазон чисел, кол-во заданий, тип).
- Вывод на экран + печать / скачивание PDF.
- **Лимит для бесплатных: 3 генерации в день.** Без ограничений — по подписке.

### 5.4 Подготовка к экзаменам
- Разделы ЕГЭ / ОГЭ / ВПР по предметам и заданиям (`/ege/angliyskiy-yazyk/zadanie-1/variant-1`).
- Варианты, разбор, тренировочные тесты с проверкой.

### 5.5 Аккаунты и роли
- Регистрация/вход (email + пароль, желательно вход через Google/VK).
- Роль «Родитель» может вести несколько детских профилей.
- Личный кабинет: прогресс, история, статус подписки.

### 5.6 Подписка и оплата
- Тариф: **299 ₽/мес** (базово; заложить возможность годового и пробного периода).
- Матрица доступа (из FAQ лендинга):
  - **Бесплатно:** теория, шпаргалки, часть тестов, генераторы (3 раза/день).
  - **По подписке:** тренажёры, рабочие листы, PDF, генераторы без лимита, полные тесты.
- Оплата через российского провайдера (ЮKassa / CloudPayments), автопродление, отмена в кабинете.
- Пейволл: при попытке открыть платный материал — экран подписки.

### 5.7 Контент-менеджмент
- Админка/CMS для добавления тем, форматов, вариантов экзаменов без правки кода.
- Возможность загружать PDF и рабочие листы.

## 6. Нефункциональные требования

- **Дизайн:** сохранить текущий стиль (тёмная тема `#0A0812`, фиолетовый `#7C3AED`, оранжевый акцент `#F97316`, радиусы 16px, шрифт system-ui). Детские разделы — светлее и крупнее.
- **Производительность:** LCP < 2.5 c на 4G, интерактив тренажёров без задержек.
- **SEO:** ЧПУ, мета-теги на каждую страницу, sitemap, Open Graph; контент в разметке для индексации (важно для органического трафика родителей).
- **Доступность:** крупные кликабельные зоны для детей, контраст, поддержка тач-устройств.
- **Аналитика:** Яндекс.Метрика / GA — воронка регистрация → активация → подписка.
- **Безопасность:** HTTPS, защита персональных данных детей (152-ФЗ), хранение платёжных данных на стороне провайдера.
- **Локализация:** интерфейс на русском (контент — русский + английский язык как предмет).

## 7. Технические рекомендации

- **Фронтенд:** React/Next.js (SSR/SSG для SEO) — тренажёры уже есть в React/TSX (`algebum v4.tsx`, `irregular-verbs.tsx`).
- **Роутинг:** файловый роутинг Next.js под схему URL из раздела 4.
- **Бэкенд:** Node.js/Next API routes или отдельный сервис; БД PostgreSQL (пользователи, прогресс, подписки, каталог).
- **Платежи:** ЮKassa/CloudPayments + вебхуки для статуса подписки.
- **Хостинг:** VPS/облако РФ (учёт 152-ФЗ), CDN для статики и PDF.
- **Миграция контента:** обернуть существующие HTML-тренажёры как компоненты/iframe на первом этапе, затем переписать в единый движок.

## 8. Этапы (roadmap)

**Этап 1 — MVP каркас**
Роутинг по URL-схеме, перенос лендинга, 5–10 рабочих тренажёров, страница подписки-заглушка, адаптив, SEO-базис.

**Этап 2 — Монетизация**
Аккаунты, роли родитель/ребёнок, оплата 299 ₽/мес, пейволл, лимиты генераторов, личный кабинет с прогрессом.

**Этап 3 — Контент и экзамены**
CMS, разделы ЕГЭ/ОГЭ/ВПР с вариантами, полный каталог предметов и тем, наполнение всех форматов.

**Этап 4 — Развитие**
Геймификация (баллы, значки, стрики), рекомендации, пробный период и годовой тариф, мобильное приложение (опционально).
